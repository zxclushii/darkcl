# plain-dark

A plain, near-black monochrome theme for the Claude Code desktop app. Colors only: no scene, no shader, no animation, so it gives the GPU nothing to redraw.

It applies itself when a session starts. `/plain-dark off` removes it and remembers that; `/plain-dark on` brings it back.

## Install

At the prompt of a terminal session:

```
/plugin install plain-dark --marketplace zxclushii/darkcl
```

From a shell:

```
claude plugin install plain-dark --marketplace zxclushii/darkcl
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `zxclushii/darkcl`, then Add plugin.
